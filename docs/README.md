## Adding a new design test

1. Create `docs/screenshots/<date>-<design-name>/`.
2. Save `1-design-html.jpg`, `2-frontend.jpg` and `3-block-editor-list-view.jpg` in it.
3. Add a row to the table above and a line to the findings file.
