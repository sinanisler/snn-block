# Style tab as Bricks lays it out, and real panel screenshots (6 Nov 2026)

## What changed

- **Style tab: one group at a time.** A rail of seven icons (Layout, Typography, Background, Gradient, Border, Transform, Filters) sits at the top of the tab, as Bricks's group rail does. The group's name and a count of the values the current view sets follow it.
- **Sections inside a group**, each under an uppercase heading, as Bricks has them: Layout has Spacing, Sizing, Positioning and Misc. Typography has Text, Alignment, Spacing and More. Border has Border and Box shadow. Filters has Filter and Transition.
- **Margin and padding as a box.** The four sides are a 2 by 2 grid with their own dots, a link toggle (one edit sets all four sides), and a Reset on Tablet and Mobile. A side the view does not set shows the value it inherits as its placeholder.
- **Icon rows.** Text align is four icons; text transform is four icons (none, Aa, AA, aa). Gradient type and the other choices stay as dropdowns.
- **Colour fields have a swatch.** The swatch shows the colour, or the colour of a chosen variable. A click opens the browser's colour picker (D17).
- **Per-view dots on Desktop too.** A value set on Desktop shows the dot, as Bricks does. Reset only appears on Tablet and Mobile.
- **Background size is a choice** (cover, contain, auto), not a length.
- **Header shows the element name** ("Section") above the view switch. Core's block card is hidden, so the panel is the only place the name appears (D57).

## Verified

- Browser, blocks.local, 1600 px viewport: the rail switches groups; Tablet sets Margin top (dot, Reset, Desktop value shown as the placeholder); Mobile inherits Tablet's value as its placeholder; Desktop keeps its own value; the link toggle sets all four sides. No console errors.
- Layout blocks PHP test 220 of 220. Layout views 21 of 21. Functional 56 of 56. (PHP suites are unchanged; they ran as a regression check.)
- Syntax: both edited scripts pass `node --check`.

## Not built (still open)

- Shape dividers (layout elements only), parallax, masonry, the background image upload and background video. Background has the image URL only.
- Attributes and Custom CSS live in Default > Advanced, not in a Style group, as before (57abd6b).
- Display, direction, justify, align and the Column and Row gap on the Default tab are not per view yet. Only the Style values are.
