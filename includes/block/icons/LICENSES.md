# Icon libraries

The icon fonts, their stylesheets and the name lists in this folder were copied from Bricks 2.4.5
(`assets/fonts`, `assets/css/libs`, `includes/html-to-bricks/icon-fonts.php`). They are open-licensed
third-party libraries, not Bricks code. The only change: the font paths in the stylesheets point to `../fonts/`.

| Library | Files | Licence |
| --- | --- | --- |
| Font Awesome Free 6 (Solid, Regular, Brands) | `fonts/fontawesome`, `css/font-awesome-6*.min.css` | Icons: CC BY 4.0. Fonts: SIL OFL 1.1. Code: MIT. https://fontawesome.com/license/free |
| Ionicons 4 | `fonts/ionicons`, `css/ionicons.min.css` | MIT. https://github.com/ionic-team/ionicons/blob/main/LICENSE |
| Themify Icons | `fonts/themify`, `css/themify-icons.min.css` | SIL OFL 1.1. https://themify.me/themify-icons |

`icon-lists.json` holds the class names per library, for the icon picker (`../../controls/icon-picker.js`).
Font Awesome brand icons are trademarks of their owners.
